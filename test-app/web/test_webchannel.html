JS world isolation

This page demonstrates how the bridge-world (WebChannel transport) is isolated from the page-world (page JS and user scripts).

JS globals are not shared between worlds, but the DOM is shared. The bridge therefore uses DOM events __sq_req__ / __sq_push__ to communicate.

Use QML controls or the in-page button to exercise the WebChannel round-trip while globals stay isolated.
